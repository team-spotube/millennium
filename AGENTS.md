# Millennium — implementation state

## Intent and conventions
- Theme Compose Unstyled 2.10.0 components; do not replace their interaction/accessibility behavior with decorative imitations.
- Visual direction: 2007 Aero / Web 2.0, refined for 2026. Pearl light surfaces, neutral zinc dark surfaces, blue gel gradients, hairline bevels, generous spacing, accessible controls and restrained motion.
- Library, Gradle module, and Maven artifact are named `millennium`; the public Kotlin package is `org.spotube.millennium`.
- Library code belongs in `millennium/src/commonMain`; interactive cross-platform gallery belongs in `sample/sharedUI`.
- State is caller-owned. Gallery preferences use saveable state where supported.
- Preserve existing scaffold functions/tests unless necessary for compatibility.

## Current progress
- `MillenniumSidebarTrigger` now delegates to `MillenniumIconButton` instead of re-implementing the button: it only adds the sidebar-toggle click and a caller-owned `content: @Composable (MillenniumSidebarTriggerVisuals) -> Unit` slot (default = the rotating chevron). All surface/interaction/motion/a11y comes from the icon button; `style` (default `Secondary`) and `iconButtonTheme` are exposed, and the sidebar trigger theme's shape/size/colors/shadow map onto the icon-button params. `MillenniumSidebarTriggerState` exposes `collapsed`, `foreground` and `rotation`. A preview demonstrates the custom slot. `:millennium:jvmTest` passes; sample hot-reloads cleanly.
- Removed two more "millennium" surface effects per feedback: `MillenniumSidebarGroupLabel` no longer paints a bevel/glossy box by default (transparent background, no border and no inner glow except for keyboard focus), and the `MillenniumTabGroup` tab list dropped its `insetShadeColor`/`bottomRimColor` inner rim (the dark 3px stroke inset from the border that read as an "inner box"). `:millennium:jvmTest` passes; sample hot-reloads cleanly.
- Fixed the "inner box" that appeared inside hovered items. Cause: `millenniumSurface` draws a drop shadow *behind* the fill, so a translucent hover wash let the shadow bleed through as a darker rounded rect inside the pill. `millenniumSurface` gained an `opaqueFill: Boolean = true` guard that skips the shadow when the background is not fully opaque; `MillenniumSidebarItem`/`MillenniumSidebarTrigger` pass it based on whether the active fill is the opaque gel/bevel or a translucent wash, and `MillenniumAutocomplete` rows pass `opaqueFill = highlighted`. Opaque surfaces (buttons, cards, panels, selected gel rows) keep their shadows unchanged. (A runtime brush-alpha sampling approach was tried and rejected: it cannot sample gradients and fails during JVM tests.) `:millennium:jvmTest` passes; sample hot-reloads cleanly.
- Upgraded overlay, navigation and control animations across the library for a spring-driven, tactile feel:
  - `DropdownMenu.kt`: `DropdownMenuPanel` now enters with an anchor-aware spring (`scaleIn` + `expandVertically`/`slideIn` from the trigger's `AnchorSide`) and exits briskly (`FastOutLinearInEasing` `fadeOut` + `scaleOut` + `shrinkVertically`/`slideOut`). Menu items animate scale with a spring on hover/focus (`1.012f`) and press (`0.975f`), plus animated foreground, border color and elevation. `MillenniumDropdownMenuThemeProperties` and `MillenniumDropdownMenu` expose `openAnimationMillis`, `closeAnimationMillis`, `enterScale` and `exitScale`. Gallery `MenuDemo` rotates its chevron with a spring when the menu opens.
  - `Dialog.kt`: `DialogPanel` now springs in (`scaleIn` + `slideInVertically` + `fadeIn`) and exits with a crisp `scaleOut` + `slideOutVertically` + `fadeOut`; the red close cap responds to hover/focus/press with spring scale, elevation and glow. `MillenniumDialogThemeProperties` and `MillenniumDialog` expose `exitScale` and `closeAnimationMillis`.
  - `Autocomplete.kt`: popup menu enters with a spring (`expandVertically` + `slideInVertically` + `scaleIn` from `TransformOrigin(0.5f, 0f)`) and exits with `FastOutLinearInEasing`; suggestion rows use a spring for hover/press scale and animate foreground, border and elevation.
  - `TabGroup.kt`: added a sliding gel selection pill under `TabList` driven by a spring (`animateDpAsState`), spring hover/press scale and animated label color per tab, plus directional `AnimatedContent` (horizontal slide + scale + fade based on tab index) for `TabPanel` transitions (`panelAnimationMillis`).
  - `Tooltip.kt`, `Disclosure.kt`, `Drawer.kt`, `ModalBottomSheet.kt`, `Snackbar.kt`, `PullToRefresh.kt`: added spring-driven enter/exit transitions (`TooltipPanel`, `DisclosedContent` + spring chevron rotation, `Drawer` scrim `Overlay` fade + spring `rememberMillenniumDrawerState`, `Snackbar` spring slide/scale/fade, `PullToRefresh` spring snap-back and indicator `AnimatedVisibility`).
  - Interactive controls (`Button.kt`, `IconButton.kt`, `SegmentedButton.kt`, `Checkbox.kt`, `RadioGroup.kt`, `ToggleSwitch.kt`, `Slider.kt`, `BottomNavigationBar.kt`, `Sidebar.kt`, `ListTile.kt`, `Progress.kt`) now use springs for scale/thumb/indicator/width motion and `animateColorAsState` for border/foreground transitions (`Checkbox` and `RadioGroup` indicators pop in with `scaleIn` springs; `ToggleSwitch` thumb slides and squishes with a spring).
- `DropdownMenu.kt` item content is now vertically centered: each row's label is wrapped in a `Box` that fills the row's minimum height with `contentAlignment = Alignment.CenterStart`, so labels no longer sit high inside the 44dp target. `:millennium:jvmTest` passes.
- Per-instance customization: every public composable now accepts a `theme` parameter defaulting to the active `MillenniumTheme.<component>Theme` (e.g. `theme: MillenniumCardTheme = MillenniumTheme.cardTheme`), plus optional named parameters for its common visual knobs (backgrounds/colors, shape, borders, elevation, padding, spacing, typography, sizes and animation durations). Overrides resolve as `param ?: themeValue ?: fallback`, so callers that pass nothing get exactly the previous behavior. Simple components got granular params for essentially every theme field; multi-section components (Button/IconButton variants, Autocomplete, Sidebar bricks, Scaffold, BottomNavigationBar) expose `theme` plus the section's parameters. `MillenniumAutocomplete` also takes a separate `textFieldTheme`. README gained a "Per-instance overrides" section; full `./gradlew build` passes (JVM tests, Firefox/wasm JS, web distribution).
