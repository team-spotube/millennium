# Millennium — implementation state

## Intent and conventions
- Theme Compose Unstyled 2.10.0 components; do not replace their interaction/accessibility behavior with decorative imitations.
- Visual direction: 2007 Aero / Web 2.0, refined for 2026. Pearl light surfaces, neutral zinc dark surfaces, blue gel gradients, hairline bevels, generous spacing, accessible controls and restrained motion.
- Library, Gradle module, and Maven artifact are named `millennium`; the public Kotlin package is `org.spotube.millennium`.
- Library code belongs in `millennium/src/commonMain`; interactive cross-platform gallery belongs in `sample/sharedUI`.
- State is caller-owned. Gallery preferences use saveable state where supported.
- Preserve existing scaffold functions/tests unless necessary for compatibility.

## Current progress

Compose Unstyled and Compose `wasm-js` artifacts publish with `compile` scope in `millennium-wasm-js`, so wasm consumers get the exported API too. `:millennium:wasmJsBrowserTest`, `:sample:webApp:wasmJsBrowserDistribution` and full `./gradlew build` pass; README lists the WebAssembly sample command.
- Compose Unstyled is exported as part of Millennium's public API: `composeunstyled` (which aggregates the full component surface), `composeunstyled-theming`, `composeunstyled-primitives` and `composeunstyled-colored-indication` remain `api` in `commonMain`. Verified in the published Gradle module metadata (present in every target's `apiElements`) and in the platform POMs (`compile` scope for Android/JVM/iOS/JS/WebAssembly), so consuming projects can write `com.composeunstyled.*` code without declaring it. The sample now depends only on `project(":millennium")` and imports Compose Unstyled directly, making `./gradlew build` a regression check for the export. README gained a "Consuming Compose Unstyled" section. Full `./gradlew build` passes.

Both light schemes share untinted `#FAFAFA` backgrounds and white surfaces. `MillenniumColorSchemes.resolve` selects light/dark role sets; `MillenniumThemeConfig.palette` selects an accent family without touching component themes. Gallery header and reference study offer a palette selector. Common contrast tests exercise text/semantic colors on neutral surfaces and every gel stop across six appearances. Full `./gradlew build` passes. Further palette families can be added by extending the enum and paired role palettes.

Fixed menu header/footer surround a scrollable results list; leading/trailing composable slots and custom row visuals supported. Popup fades/expands/scales in and fades/shrinks/scales out with independently configurable open/close durations. Row hover/highlight animates border, elevation and subtle scale; `itemStateAnimationMillis` is configurable. `MillenniumAutocompleteTheme` registered under `MillenniumTheme`. Gallery adds artist search with save actions and keyboard help (23 components). - `Card.kt` provides the public `MillenniumCard` raised Aero/glass surface. Shared state and surface primitives live in `theme/Utils.kt`; `Theme.kt` owns the global light/dark palettes, groups component themes, and installs the active palette and defaults.

Component-local properties include that component's dimensions, spacing, typography, shapes, elevation/strokes, motion, and optional visual overrides. Palette roles live once in `MillenniumThemeConfig.colorSchemes`; component defaults resolve against `MillenniumTheme.colors` and do not copy/store a palette. No global dimensions/spacing/shape/stroke/elevation/typography buckets remain. Button variants have separately configurable primary/secondary/quiet/danger state properties, including animation settings.
- `theme/Utils.kt` contains shared state-property and single-layer surface primitives. `theme/Preview.kt` owns the shared `MillenniumPreview` frame; component `@Preview`s remain in their own files.

- Shared interactive gallery in `sample/sharedUI/src/commonMain/kotlin/sample/app/App.kt`: category filtering, responsive 1–3 column layouts, light/dark switch, parent/child tri-state selection, input validation, tabs, menus, progress and overlays.
- Sample state uses `rememberSaveable`, `rememberTextFieldState` and per-card `SaveableStateProvider` so control values survive category filtering; it is not persisted to disk across app restarts. Overlay state follows Compose Unstyled's state APIs.
- Renamed the module and artifact from the numeric `2000s` name to `millennium`; Gradle project references, Maven coordinates, publishing paths, README, sample branding and legacy IDEA artifact configs now use Millennium.
- Android namespaces and Maven coordinates use `org.spotube.millennium`; Maven artifact and Gradle module are now `millennium`.
